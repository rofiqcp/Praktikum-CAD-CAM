# PROJECT MODUL 14: CAM — LASER CUTTING AKRILIK + THERMAL BENDING

## Deskripsi
Modul penutup seri CAD/CAM: pembuatan **casing box** akrilik (flat-pack assembly) dan **casing body melengkung** menggunakan teknik Sheet Metal → Flatten → Laser Cut + Scoring → Thermal Bending.

## Spesifikasi Project

### A. Casing Box (Flat-Pack)
| Parameter | Spesifikasi |
|-----------|-------------|
| Dimensi | ~100 × 80 × 60 mm (bisa disesuaikan) |
| Material | Akrilik cast 3mm |
| Sambungan | Tab-slot interlocking ± lem akrilik |
| Panel | 6 panel (top, bottom, front, back, left, right) |
| Tab | Lebar 10mm, slot 3.1mm (clearance 0.1mm) |

### B. Casing Body Melengkung (Thermal Bending)
| Parameter | Spesifikasi |
|-----------|-------------|
| Material | Akrilik cast 3mm |
| Teknik Desain | SolidWorks Sheet Metal → Flatten |
| Bend Radius | ≥15mm (kurva smooth) |
| Scoring | Laser engrave pada bend lines (power 15–25%) |
| Bending | Heat gun / strip heater, suhu 150–170°C |
| Jig | Cetakan kurva dari MDF/kayu |

## Catatan Penting
- **SAFETY WAJIB**: Glasses + sarung tangan tahan panas + masker
- **Test bending dulu** pada potongan sisa akrilik — JANGAN langsung pada part final!
- **Akrilik CAST** (bukan extruded) — pastikan tipe material benar
- **Scoring ≠ Cutting** — power scoring harus JAUH lebih rendah (~15–25% vs 70–90%)
- **Thermal bending ≠ Press brake** — panaskan area LEBAR, bengkokkan PERLAHAN, hasilkan KURVA
- **Jig WAJIB** untuk hasil bending yang konsisten dan akurat
- **Jangan terburu-buru** saat bending — akrilik yang dipaksakan akan PECAH
- **Hold posisi** sampai dingin (~30 detik) — springback minimal tapi tetap ada
