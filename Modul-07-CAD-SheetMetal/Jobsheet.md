# JOBSHEET MODUL 7: CAD SHEET METAL

## Praktikum CAD/CAM — Pertemuan 7

---

## I. Tujuan Praktikum
1. Mahasiswa mampu mendesain komponen sheet metal di SolidWorks
2. Mahasiswa mampu menggunakan Base Flange, Edge Flange, Miter Flange, Hem, dan Jog
3. Mahasiswa mampu menggunakan Forming Tools
4. Mahasiswa mampu membuat Flat Pattern dan mengekspor ke DXF
5. Mahasiswa memahami K-Factor dan parameter bend

## V. Analisa dan Pembahasan
1. Jelaskan pengaruh K-Factor terhadap dimensi flat pattern
2. Bandingkan sheet metal design vs solid modeling untuk komponen plat
3. Analisis proses dari desain digital → flat pattern → laser cut → bending
4. Diskusikan pertimbangan desain: minimum bend radius, relief type
5. Jelaskan keunggulan Tab & Slot design untuk proses fabrikasi
