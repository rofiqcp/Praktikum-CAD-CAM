# PROJECT MODUL 1: PORTFOLIO SETUP & KONFIGURASI LINGKUNGAN KERJA

## Praktikum CAD/CAM — Pertemuan 1

---

## Deskripsi Project

Project Modul 1 adalah **rangkuman dari 10 percobaan** yang telah dilakukan. Praktikan diminta untuk membuat **Portfolio Digital Setup** yang mendokumentasikan seluruh konfigurasi lingkungan kerja CAD/CAM.

---

## Tujuan Project

1. Memastikan seluruh software terinstal dan terkonfigurasi dengan benar
2. Membuat dokumentasi lengkap lingkungan kerja
3. Menguji kesiapan untuk modul-modul selanjutnya
4. Melatih kemampuan dokumentasi teknis

---

## Deliverables

### 1. Dokumen Konfigurasi (PDF)
Buat dokumen PDF yang berisi:

#### a. Spesifikasi Komputer
- Processor, RAM, GPU, Storage
- Sistem Operasi
- Screenshot System Information

#### b. Screenshot Semua Software Terinstal
- SolidWorks (dengan versi dan lisensi terlihat)
- CorelDRAW
- Fusion 360
- Cura
- OBS Studio

#### c. Konfigurasi SolidWorks
- Screenshot pengaturan Unit (MMGS)
- Screenshot pengaturan Template (ISO)
- Screenshot pengaturan Performance
- Screenshot Custom Shortcut (jika ada)

#### d. Struktur Folder Kerja
```
D:\Praktikum-CADCAM\
├── Modul-01\
│   ├── Percobaan\
│   ├── Project\
│   ├── Video\
│   └── Laporan\
├── Modul-02\
├── ...
└── Modul-14\
```
Screenshot folder yang sudah dibuat.

### 2. File SolidWorks Test
Buat file-file berikut untuk menguji bahwa SolidWorks berjalan dengan baik:

#### a. Part Sederhana
- Buat balok 50x30x20mm
- Tambahkan fillet R5 pada satu edge
- Simpan sebagai `.sldprt` dan ekspor ke `.step` dan `.stl`

#### b. Assembly Sederhana
- Masukkan part balok 2x
- Buat mate coincident
- Simpan sebagai `.sldasm`

#### c. Drawing Sederhana
- Buat drawing dari part balok
- Masukkan 3 view (Front, Top, Right)
- Tambahkan dimensi
- Simpan sebagai `.slddrw` dan ekspor ke `.pdf`

### 3. Test Export untuk Setiap Workflow
#### a. Test Laser Cutting
- Export drawing ke DXF
- Buka DXF di CorelDRAW
- Screenshot berhasil dibuka

#### b. Test 3D Printing
- Export part ke STL
- Buka STL di Cura
- Coba slice
- Screenshot preview slicing

#### c. Test CNC Milling
- Export part ke STEP
- Import STEP di Fusion 360
- Screenshot berhasil dibuka

### 4. Video Demonstrasi (3-5 menit)
Rekam video singkat yang menunjukkan:
- Membuka SolidWorks dan membuat part sederhana
- Export ke berbagai format
- Membuka file di software pendukung
- Narasi menjelaskan setiap langkah
