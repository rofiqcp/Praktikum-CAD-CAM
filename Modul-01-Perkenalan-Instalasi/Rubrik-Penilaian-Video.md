# RUBRIK PENILAIAN VIDEO — PRAKTIKUM CAD/CAM

## Berlaku untuk Semua Modul (Modul 1 - 14)

---

## Komponen Video yang Dinilai

### A. Penjelasan Materi (30 poin)

| Skor | Kriteria |
|------|----------|
| **25-30** (Sangat Baik) | Menjelaskan semua konsep materi dengan benar, lengkap, dan sistematis. Menggunakan istilah teknis yang tepat. Memberikan contoh dan analogi yang membantu pemahaman. |
| **19-24** (Baik) | Menjelaskan sebagian besar konsep dengan benar. Beberapa istilah teknis digunakan dengan tepat. Penjelasan cukup sistematis. |
| **13-18** (Cukup) | Menjelaskan konsep dasar namun kurang lengkap. Beberapa kesalahan dalam penggunaan istilah. Penjelasan kurang sistematis. |
| **7-12** (Kurang) | Penjelasan materi minimal dan banyak kesalahan. Istilah teknis jarang digunakan atau salah. Tidak sistematis. |
| **0-6** (Sangat Kurang) | Tidak menjelaskan materi atau penjelasan sangat tidak sesuai. |

### B. Demonstrasi Percobaan 1-10 - Screen Record (30 poin)

| Skor | Kriteria |
|------|----------|
| **25-30** (Sangat Baik) | Semua 10 percobaan didemonstrasikan dengan jelas di layar. Setiap langkah dijelaskan secara detail. Hasil percobaan ditampilkan dengan benar. Screen record berkualitas baik. |
| **19-24** (Baik) | 7-9 percobaan didemonstrasikan. Sebagian besar langkah dijelaskan. Hasil ditampilkan. |
| **13-18** (Cukup) | 5-6 percobaan didemonstrasikan. Penjelasan langkah kurang detail. Beberapa hasil tidak ditampilkan. |
| **7-12** (Kurang) | 3-4 percobaan didemonstrasikan. Penjelasan minimal. |
| **0-6** (Sangat Kurang) | Kurang dari 3 percobaan atau tidak ada demonstrasi. |

### C. Demonstrasi Project - Screen Record (15 poin)

| Skor | Kriteria |
|------|----------|
| **13-15** (Sangat Baik) | Project didemonstrasikan secara lengkap dengan penjelasan yang jelas. Semua komponen project terlihat. |
| **10-12** (Baik) | Project didemonstrasikan dengan baik, beberapa detail kurang. |
| **7-9** (Cukup) | Project didemonstrasikan sebagian. Penjelasan kurang. |
| **4-6** (Kurang) | Demonstrasi project minimal. |
| **0-3** (Sangat Kurang) | Tidak mendemonstrasikan project. |

### D. Eksekusi CAM dengan Rekaman HP (Khusus Modul CAM: 10, 12, 13, 14) (10 poin)

| Skor | Kriteria |
|------|----------|
| **9-10** (Sangat Baik) | Proses eksekusi di mesin direkam dengan jelas menggunakan HP. Seluruh proses terlihat dari awal hingga akhir. Hasil produk ditampilkan. Narasi menjelaskan proses. |
| **7-8** (Baik) | Proses terekam dengan baik, beberapa bagian kurang jelas. |
| **5-6** (Cukup) | Proses terekam sebagian. Kualitas video kurang. |
| **3-4** (Kurang) | Rekaman sangat singkat atau tidak jelas. |
| **0-2** (Sangat Kurang) | Tidak ada rekaman eksekusi mesin. |

> *Catatan: Untuk modul non-CAM, 10 poin ini dialihkan ke komponen Penjelasan Materi (total 40 poin)*

### E. Analisa dan Kesimpulan (10 poin)

| Skor | Kriteria |
|------|----------|
| **9-10** (Sangat Baik) | Analisa mendalam dan relevan. Kesimpulan mencakup semua aspek percobaan dan project. Refleksi pembelajaran yang baik. |
| **7-8** (Baik) | Analisa cukup baik. Kesimpulan mencakup sebagian besar aspek. |
| **5-6** (Cukup) | Analisa dasar. Kesimpulan singkat. |
| **3-4** (Kurang) | Analisa minimal. Kesimpulan tidak relevan. |
| **0-2** (Sangat Kurang) | Tidak ada analisa atau kesimpulan. |

### F. Kualitas Teknis Video (5 poin)

| Skor | Kriteria |
|------|----------|
| **5** (Sangat Baik) | Resolusi min. 1080p, audio jernih, pencahayaan baik, wajah terlihat, screen record smooth. Durasi sesuai ketentuan. |
| **4** (Baik) | Resolusi min. 720p, audio cukup jelas, wajah terlihat. |
| **3** (Cukup) | Resolusi cukup, audio bisa didengar, wajah kadang terlihat. |
| **2** (Kurang) | Resolusi rendah, audio tidak jelas, wajah tidak terlihat. |
| **0-1** (Sangat Kurang) | Kualitas sangat buruk atau video corrupt. |

|------|-------|----------|
| 85-100 | A | Sangat Baik |
| 70-84 | B | Baik |
| 56-69 | C | Cukup |
| 41-55 | D | Kurang |
| 0-40 | E | Sangat Kurang |

---

## Ketentuan Tambahan

1. **Keterlambatan**: Pengurangan 10 poin per hari keterlambatan (maks. 3 hari)
2. **Plagiarisme**: Nilai 0 jika terbukti menjiplak video orang lain
3. **Format file**: MP4, maksimal 500MB per video
4. **Durasi**: 
   - Modul non-CAM: 10-15 menit
   - Modul CAM: 15-20 menit (termasuk rekaman eksekusi mesin)
5. **Wajah wajib terlihat** minimal saat penjelasan materi dan analisa
6. **Narasi wajib** menggunakan bahasa Indonesia yang baik dan benar
