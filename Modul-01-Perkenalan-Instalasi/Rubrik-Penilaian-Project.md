## Komponen Penilaian Project

### A. Pemahaman Konsep & Penerapan Materi (25 poin)

| Skor | Kriteria |
|------|----------|
| **21-25** (Sangat Baik) | Project menunjukkan pemahaman mendalam terhadap semua konsep dari percobaan 1-10. Teknik-teknik yang dipelajari diterapkan dengan tepat dan kreatif. Tidak ada kesalahan konseptual. |
| **16-20** (Baik) | Pemahaman baik terhadap sebagian besar konsep. Teknik diterapkan dengan benar. Sedikit kesalahan minor. |
| **11-15** (Cukup) | Pemahaman dasar terhadap konsep. Beberapa teknik diterapkan. Ada beberapa kesalahan. |
| **6-10** (Kurang) | Pemahaman terbatas. Sedikit teknik yang diterapkan. Banyak kesalahan. |
| **0-5** (Sangat Kurang) | Tidak menunjukkan pemahaman konsep. |

### B. Kualitas Desain / Model 3D (25 poin)

| Skor | Kriteria |
|------|----------|
| **21-25** (Sangat Baik) | Model 3D presisi, sketch fully defined, feature tree terorganisir rapi. Dimensi akurat sesuai spesifikasi. Tidak ada error. Design intent jelas. |
| **16-20** (Baik) | Model baik, sebagian besar sketch fully defined. Dimensi cukup akurat. Feature tree cukup terorganisir. |
| **11-15** (Cukup) | Model dibuat namun ada beberapa issue. Beberapa sketch under-defined. Feature tree kurang rapi. |
| **6-10** (Kurang) | Model tidak presisi. Banyak sketch under-defined. Feature tree berantakan. |
| **0-5** (Sangat Kurang) | Model tidak dapat dibuat atau sangat tidak sesuai. |

### C. Kompleksitas & Kreativitas (20 poin)

| Skor | Kriteria |
|------|----------|
| **17-20** (Sangat Baik) | Project menunjukkan tingkat kompleksitas tinggi. Menggunakan berbagai fitur dan teknik. Ada inovasi/kreativitas dalam desain. Melampaui requirement minimum. |
| **13-16** (Baik) | Kompleksitas memadai. Menggunakan beberapa fitur beragam. Ada sentuhan kreatif. |
| **9-12** (Cukup) | Kompleksitas dasar. Menggunakan fitur minimum. Kurang kreativitas. |
| **5-8** (Kurang) | Terlalu sederhana. Hanya menggunakan 1-2 fitur. |
| **0-4** (Sangat Kurang) | Tidak memenuhi standar minimum kompleksitas. |

### D. Kelengkapan Deliverables (15 poin)

| Skor | Kriteria |
|------|----------|
| **13-15** (Sangat Baik) | Semua file yang diminta lengkap. Format penamaan benar. Organisasi folder rapi. Dokumentasi (screenshot/drawing) lengkap. |
| **10-12** (Baik) | Sebagian besar file lengkap. Format penamaan sebagian benar. |
| **7-9** (Cukup) | Beberapa file kurang. Format penamaan kurang konsisten. |
| **4-6** (Kurang) | Banyak file kurang. Tidak terorganisir. |
| **0-3** (Sangat Kurang) | File sangat tidak lengkap atau tidak dikumpulkan. |

### E. Kemampuan Manufaktur / Feasibility (15 poin)

#### Untuk Modul CAD (Modul 1-9, 11):
| Skor | Kriteria |
|------|----------|
| **13-15** (Sangat Baik) | Desain dapat diproduksi (manufacturable). Mempertimbangkan toleransi, material, dan proses manufaktur. Assembly dapat dirakit dengan benar. |
| **10-12** (Baik) | Desain sebagian besar dapat diproduksi. Beberapa pertimbangan manufaktur. |
| **7-9** (Cukup) | Desain cukup realistis namun ada issue manufaktur. |
| **4-6** (Kurang) | Desain sulit diproduksi. Tidak mempertimbangkan manufaktur. |
| **0-3** (Sangat Kurang) | Desain tidak dapat diproduksi sama sekali. |

#### Untuk Modul CAM (Modul 10, 12, 13, 14):
| Skor | Kriteria |
|------|----------|
| **13-15** (Sangat Baik) | Produk berhasil diproduksi dengan kualitas baik. Parameter mesin tepat. Hasil sesuai desain. Efisiensi material baik. |
| **10-12** (Baik) | Produk berhasil diproduksi. Beberapa parameter perlu adjustment. |
| **7-9** (Cukup) | Produk diproduksi namun ada defect. Parameter kurang optimal. |
| **4-6** (Kurang) | Produk gagal sebagian. Parameter tidak tepat. |
| **0-3** (Sangat Kurang) | Produk gagal total atau tidak dieksekusi. |

## Ketentuan Tambahan

1. **Keterlambatan**: Pengurangan 10 poin per hari keterlambatan (maks. 3 hari, setelah itu tidak diterima)
2. **Plagiarisme**: Nilai 0 jika terbukti menjiplak project orang lain
3. **Revisi**: Diperbolehkan 1x revisi dengan pengurangan 10% dari nilai maksimal
4. **Project CAM**: Wajib dieksekusi di mesin (bukan hanya desain digital)
5. **File corrupt**: Praktikan bertanggung jawab atas integritas file yang dikumpulkan
