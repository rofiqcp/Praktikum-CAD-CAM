# PROJECT MODUL 12: PRODUK 3D PRINT — PART ROBOT FUNGSIONAL

## Deskripsi
Produksi **3-5 part robot** (dari Modul 9 atau 11) menggunakan 3D printing. WAJIB dieksekusi di 3D printer.

## Deliverables:
1. File SolidWorks (.sldprt) — semua part (modifikasi untuk printability)
2. File STL — semua part
3. File G-code — dari slicer
4. Screenshot slicer settings
5. **Produk fisik** — part 3D printed
6. Foto dimensi terukur (caliper) vs desain
7. **Video proses printing** (rekaman HP)
8. Laporan: desain → print → evaluasi kualitas

## Kriteria Penilaian
| Kriteria | Bobot |
|----------|-------|
| Design for 3D Printing | 20% |
| Parameter setting optimal | 15% |
| Kualitas print | 25% |
| Akurasi dimensi | 20% |
| Dokumentasi (foto, video) | 20% |
