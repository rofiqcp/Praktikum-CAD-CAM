# JOBSHEET MODUL 10: CAM LASER CUTTING — REALISASI ROBOT BERODA + TULISAN NAMA

## Praktikum CAD/CAM — Pertemuan 10

---

## I. Tujuan Praktikum
1. Mahasiswa mampu mengeksport DXF dari SolidWorks untuk laser cutting
2. Mahasiswa mampu mengolah file di CorelDRAW (warna layer, nesting, text to curves)
3. Mahasiswa mampu membuat engraving tulisan nama dan logo pada akrilik
4. Mahasiswa mampu menggunakan software laser (RDWorks/LightBurn) dan menentukan parameter
5. Mahasiswa mampu mengeksekusi proses laser cutting dan engraving
6. Mahasiswa mampu merakit robot beroda flat-pack dari panel akrilik laser cut

---

## II. Alat dan Bahan
| No | Alat/Bahan | Keterangan |
|----|------------|------------|
| 1 | Laptop/PC + SolidWorks + CorelDRAW | Software |
| 2 | Mesin Laser CO₂ | 60–80W |
| 3 | Akrilik 3mm (400×600mm atau lebih) | Material utama — untuk robot + name tag |
| 4 | Akrilik 5mm (opsional) | Untuk part konveyor (Modul 8) |
| 5 | HP/Smartphone | Rekaman eksekusi mesin + assembly |
| 6 | Kacamata pelindung | Keselamatan |
| 7 | Amplas halus (P400+) | Finishing edge |

---

## III. Landasan Teori
Lihat **Materi.md** Modul 10 untuk teori laser cutting, parameter, workflow, dan teknik engraving.

## IV. Langkah Percobaan
| No | Percobaan | Software/Alat |
|----|-----------|---------------|
| 1 | Export DXF panel robot | SolidWorks |
| 2 | Setup engraving nama di CorelDRAW | CorelDRAW |
| 3 | Buat name tag terpisah (engrave) | SW + CorelDRAW |
| 4 | Nesting semua panel + name tag | CorelDRAW |
| 5 | Import ke software laser + parameter | RDWorks/LightBurn |
| 6 | Test cut dan parameter tuning | Mesin Laser + HP |
| 7 | Eksekusi laser cutting panel robot | Mesin Laser + HP |
| 8 | Eksekusi laser engraving tulisan nama | Mesin Laser + HP |
| 9 | Assembly robot beroda fisik | Manual + HP |
| 10 | Dokumentasi & quality check | Foto + Video |

---

## V. Analisa dan Pembahasan
1. Jelaskan pengaruh power dan speed terhadap kualitas potongan akrilik
2. Analisis kerf width dan pengaruhnya terhadap presisi tab-slot interlocking
3. Diskusikan perbedaan cutting vs raster engraving vs vektor engraving
4. Bagaimana strategi nesting memengaruhi efisiensi material? Hitung waste percentage
5. Evaluasi kualitas engraving nama — kontras, keterbacaan, kedalaman
6. Analisis fit tab-slot pada assembly robot — apa yang perlu diperbaiki?

---

## VI. Kesimpulan
Rangkum workflow lengkap: CAD (Modul 9) → DXF → CorelDRAW → Laser Cut + Engrave → Assembly Robot.
