# PROJECT MODUL 4: JOYSTICK CONTROLLER + AKSESORIS ALUMINIUM

## Praktikum CAD/CAM — Pertemuan 4

---

## Project A: Joystick Controller

### Deskripsi
Desain **Joystick Controller** yang memanfaatkan semua feature lanjutan dari Percobaan 1-10.

### Part yang Dibuat:
1. **Body Housing** — Loft dari 3 profil ergonomis + Shell + Dome
2. **Joystick Stick** — Sweep dengan profil taper
3. **Joystick Knob** — Loft sphere-like shape
4. **Button Caps** (4 buah) — Dome pada silinder kecil
5. **Base Plate** — Extrude dengan Circular Pattern screw holes
6. **Label Plate** — Wrap text pada permukaan lengkung body

---

## Project B: Aksesoris Profil Aluminium

### Deskripsi
Buat **aksesoris profil aluminium** yang umum digunakan untuk menyambung profil. Menggunakan Loft, Sweep, dan feature lanjutan lainnya.

### Aksesoris yang Harus Dibuat:

#### 1. Corner Bracket 90° untuk Profil 3030
```
Referensi: Aluminium Catalog halaman 18-19
- Diecast style bracket
- 90° angle connection
- 2 lubang M6 untuk T-Nut
- Dimensi: 28x28x26mm
- Material: Aluminum Diecast
Feature: Extrude + Fillet + Chamfer + Pattern
```

#### 2. T-Nut M6 untuk Slot 8mm
```
Referensi: Aluminium Catalog halaman 23-24
- Spring-loaded drop-in T-Nut
- Lebar: 13.5mm, Tebal: 8mm
- Lubang berulir: M6
Feature: Extrude + Revolve (ulir) + Chamfer
```

#### 3. End Cap untuk Profil 4040
```
Referensi: Aluminium Catalog halaman 55
- Plastik clip-on end cap
- Sesuai profil 4040 (40x40mm)
- Ketebalan: 5mm
- Material: Plastic (Nylon)
Feature: Extrude + Fillet
```

#### 4. Handle Plastic
```
Referensi: Aluminium Catalog halaman 26, 96
- Pegangan plastik untuk pintu/panel
- Panjang: ~130mm
- 2 lubang mounting Ø8mm dan Ø14mm
- Profil ergonomis
Feature: Loft + Sweep + Fillet
```

#### 5. Gusset Plate / Reinforcement Bracket
```
- Plat penguat sudut segitiga
- Ukuran: 40x40mm, tebal 4mm
- 2 slot untuk T-nut (slot width 8mm)
- Material: Aluminum 6061-T6
- Fillet R5 pada sudut luar
Feature: Extrude + Cut Extrude (slot)
```
