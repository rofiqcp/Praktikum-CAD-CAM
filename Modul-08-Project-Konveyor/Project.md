# PROJECT MODUL 8: KONVEYOR BELT MINI — DESAIN LENGKAP SIAP FABRIKASI

## Deskripsi
Finalisasi desain konveyor belt mini dari Percobaan 1–10 menjadi **design package lengkap** yang siap difabrikasi di modul-modul berikutnya.

---

## Konsep Project
Konveyor belt mini menggunakan:
- **Motor NEMA 17** sebagai penggerak utama
- **Profil aluminium 2040/2020** sebagai rangka
- **Dudukan/holder dari akrilik** yang akan di-laser cut (Modul 10)
- **Part struktural dari MDF/kayu** yang akan di-CNC milling (Modul 13)

---

## Deliverables

### 1. File CAD
| Item | Qty Min | Format |
|------|---------|--------|
| Part files (.sldprt) | 15+ unique parts | SolidWorks |
| Assembly file (.sldasm) | 1 (semua part terakit) | SolidWorks |

### 2. Manufacturing Files
| Item | Format | Untuk |
|------|--------|-------|
| DXF — End plates, holders, bearing housing, side guide | .dxf | Laser Cut (Modul 10) |
| STEP — Bearing block, motor mounting plate, name plate | .step | CNC Milling (Modul 13) |
| STL — Part opsional (cover, clip, dll.) | .stl | 3D Print (Modul 12) |

### 3. Dokumentasi
| Item | Format |
|------|--------|
| Exploded View dengan balloons | Di assembly / drawing |
| BOM (Bill of Materials) dengan qty, material, sumber, proses | Excel / PDF |
| Assembly drawing + dimensi keseluruhan | Drawing (.slddrw / .pdf) |
| Detail drawing 5 part custom | Drawing (.slddrw / .pdf) |
| Tabel mapping: part → proses manufaktur → modul | Di BOM |

### 4. Video
| Item | Durasi |
|------|--------|
| Penjelasan konsep + demo desain + analisa | 10–15 menit |

---

## Spesifikasi Minimum
- Motor: NEMA 17 Stepper dengan dimensi mounting akurat
- Bearing: 608ZZ (Ø22×8mm, bore Ø8mm) — minimal 4 buah
- Roller: Ø25mm, panjang 100mm — 2 buah (drive + idler)
- Frame: Profil aluminium 2040 + 2020
- Tensioning system pada idler side (slot, bukan lubang)
- Part akrilik minimal 5 jenis (end plate, holder, bearing housing, side guide)
- Part milling minimal 2 jenis (bearing block, name plate)
