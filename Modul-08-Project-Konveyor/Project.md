# PROJECT MODUL 8: KONVEYOR LENGKAP SIAP PRODUKSI

## Deskripsi
Finalisasi desain konveyor dari Percobaan 1-10 menjadi **design package lengkap**.

## Deliverables:
1. Semua part files (.sldprt) — minimal 15 unique parts
2. Assembly file (.sldasm) — dengan semua mate benar
3. Exploded View dengan balloons
4. BOM (Bill of Materials) dengan quantity
5. Drawing Package:
   - Assembly drawing dengan dimensi keseluruhan
   - Detail drawing untuk 5 part custom (non-standard)
   - Flat pattern drawing untuk part sheet metal
6. Motion Study: Roller berputar

## Kriteria Penilaian
| Kriteria | Bobot |
|----------|-------|
| Kelengkapan desain | 25% |
| Assembly benar & fungsional | 25% |
| Drawing package lengkap | 20% |
| BOM akurat | 15% |
| Kreativitas & detail | 15% |
