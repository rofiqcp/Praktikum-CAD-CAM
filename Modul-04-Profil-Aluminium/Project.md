# PROJECT MODUL 4: DESAIN FRAME SEDERHANA DARI PROFIL ALUMINIUM

## Praktikum CAD/CAM — Pertemuan 4

---

## Deskripsi Project
Desain **frame kubus 300x300x300mm** menggunakan profil aluminium 2020 beserta aksesoris sambungannya. Project ini merangkum pemahaman tentang profil aluminium dan aksesoris dari Percobaan 1-10.

## Spesifikasi:
- 12 batang profil 2020 (sesuai dimensi kubus)
- 8 corner bracket di setiap sudut
- T-nut dan bolt untuk setiap sambungan
- End cap pada ujung yang terbuka
- 4 leveling foot pada kaki bawah

## Deliverables:
1. Semua file part (.sldprt)
2. File assembly (.sldasm) - frame terakit
3. Bill of Materials (BOM)
4. Drawing 3-view dengan dimensi

## Kriteria Penilaian
| Kriteria | Bobot |
|----------|-------|
| Kelengkapan part | 20% |
| Ketepatan dimensi profil | 25% |
| Assembly dengan mate benar | 25% |
| BOM lengkap | 15% |
| Drawing dengan dimensi | 15% |
